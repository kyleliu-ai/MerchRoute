## 变体目录打开合同

“本地导入图片 → 导入产品 → 选择媒体目录”中，平台下的变体名称会打开该名称对应的本地来源文件夹，包括无子目录和已导入目录。只作用于名称按钮，保留页面地址、面包屑、勾选、预览和编辑内容；平台名称与操作列的页面内浏览行为不变。

`POST /api/v1/local-import/directories/open-folder` 接收 `{ relativePath, configHash }`，成功返回 `202 { accepted: true }`。服务器从启用的 E000 `inputQueueRoot` 解析当前目录，校验配置指纹、严格的平台/变体两级路径、存在性、可读性与真实路径，拒绝越界、符号链接和 junction。接口纳入既有旧根目录兼容保护。

Windows 与 macOS 复用审核工作台的目录启动器，分别调用 `explorer.exe` 和 `/usr/bin/open`，使用单个完整路径参数、无 shell，Windows 保留可见窗口选项。审核任务目录自身的校验不变。请求期间只禁用该名称入口；失败显示可读错误，不跳转。

202 表示已向系统启动器提交请求，不代表每台机器都已显示窗口。本批次 Windows 隔离实机验收通过窗口接口核对了实际目标目录与可见状态；macOS 命令合同测试和 macOS Finder 实机验收须分别报告，不冒称已做后者。

## 验收与交付门禁

- 服务与 API：正常路径、中文/空格/特殊字符、缺失或移动目录、配置变化、停用流程、两级限制、越界、链接目录、系统启动失败和不支持平台。自动测试注入假启动器。
- 浏览器：名称点击请求、选择/预览不变、防重复点击、错误提示、平台和操作列导航、既有审核工作台入口。
- 批次：固定工具链、隔离数据库与媒体、完整检查、集成/E2E、即梦和工作流补丁回归、敏感信息扫描、精确提交对应的独立运行包。
- 发布：中文新旧安装路径、PowerShell 5.1/7、精确进程身份、安全停止、真实启动与失败回滚、桌面/开机入口、端口和 Base URL、指针与资产哈希演练。失败记录留在仓库外，不用成功记录覆盖失败现场。
- 修正了候选版本的共享包依赖引用，并把工作区版本一致性加入安装前检查；CI 支持直接验证当前 `work/` 分支，不要求另建发布分支。
- 按本批次授权选择性提交及推送同一分支，复用一个 Draft PR。正式版本仅在所有门禁通过后统一发布；不合并 PR。正式发布与本机生产切换是不同动作，后者仍需单独确认具体候选、范围和回滚方案。
