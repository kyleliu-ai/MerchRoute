# 用户操作指南

## 工作台

顶部流程带显示 E006→E001→E002→E003，并从 E003 分流到 E004/E005。阶段卡片显示待审核、草稿、待投递或输入队列数量。

## 审核图片

1. 进入 E006、E001、E002 或 E003。
2. 打开一个产品文件夹。
3. 左侧选择子目录，中间勾选图片，右侧复核全部已选图片。
4. 点击“保存草稿”可稍后继续。
5. 点击“审核通过”，选择目标阶段并加入待投递清单。

快捷键：

- `←/→`：预览上一张/下一张。
- `Space`：选择或取消当前预览图。
- `Esc`：关闭预览。
- `Ctrl+S` / `Cmd+S`：保存草稿。
- `A`：当前目录全选。
- `Shift+A`：清除当前目录选择。

输入框获得焦点时不会触发快捷键。

## 批量投递

1. 打开“待投递清单”。
2. 勾选多个产品/目标项。
3. 选择重名策略：默认“跳过”，或“创建修订版本”。
4. 点击“批量投递”。
5. 在进度抽屉查看验证、复制、清单、READY、入队和归档步骤。

每个产品始终生成独立任务文件夹。某项失败不会阻止其他项。监听目录成功但归档失败时，“重试失败项”只补归档，不覆盖或删除已投递目录。

## 系统设置

- 修改和验证六阶段路径。
- 配置 `preserve-relative` 或 `flatten` 打包模式。
- 设置并发数 1～4。
- 维护工作流参数的默认值与下拉选项；当前 E003/E004 多值选项基线见[工作流参数下拉选项](WORKFLOW-PARAMETER-OPTIONS.md)。
- 导入或导出配置。
- 查看及清理缩略图缓存。
- 仅清理超过 24 小时的 `.staging` 残留目录。

## 真实 G 盘验收

真实验收会创建带 `CODEX-V001-ACCEPT-<时间戳>` 前缀的候选、监听和归档目录。运行前必须暂停相关 n8n 定时工作流：

```powershell
./scripts/run-real-acceptance.ps1 -ConfirmN8nPaused
```

验收覆盖 10 产品批量、E003 双目标和 `__R02` 冲突修订。产物不会自动删除，报告保存在 `acceptance-results/`。
